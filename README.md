# 📱 Rentalz Mobile App

Welcome to your Expo app 👋  
This project is a **mobile application for renting home appliances**, built using modern technologies to ensure a smooth and user-friendly experience.

---

## 🚀 Project Overview

The **Rentalz Mobile Application** is designed to simplify the process of renting home appliances. It provides a seamless mobile experience where users can browse products, place orders, and manage rentals efficiently.

Unlike traditional web-based platforms, this app focuses on:
- 📱 Mobile-first design  
- ⚡ Fast and smooth user experience  
- 🔐 Secure authentication  
- 🛒 Easy rental management  

---

## 🛠️ Tech Stack

- **Frontend:** React Native (Expo)  
- **Backend:** Firebase  
- **Authentication:** Clerk (Google Sign-In)  
- **Database:** Firebase Realtime Database  
- **Tools:** Expo CLI, EAS, VS Code  

---

## 📦 Features

- 🔐 Google Authentication  
- 📊 Real-time product display  
- 🏠 Address storage for quick checkout  
- 🛒 Easy order placement  
- 📦 Order confirmation system  
- 📱 Cross-platform support (Android & iOS)  

---

## 📂 Modules

### 1. Authentication
- Secure login using Google Sign-In  
- Fast and user-friendly access  

### 2. Data Display
- Fetches and displays products from Firebase  
- Shows images, descriptions, and pricing  

### 3. Address Storage
- Save and manage delivery addresses  
- Faster checkout experience  

### 4. Order Placement
- Select product and rental duration  
- Confirm order with details
  
---

## ⚙️ System Requirements

### 💻 Hardware
- Intel i5 or higher  
- 8GB RAM or more  
- 256GB SSD  

### 📱 Mobile Testing
- Android 8.0+  
- iOS 12+
